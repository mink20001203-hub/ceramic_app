# Portfolio Capture Checklist

## Capture Flow Order
1. Home
2. Detail
3. Cart
4. Checkout
5. Order Complete
6. My Page
7. User Order List

## File Name Convention
- `01_home.png`
- `02_detail.png`
- `03_cart.png`
- `04_checkout.png`
- `05_order_complete.png`
- `06_my_page.png`
- `07_order_list.png`

## Capture Rules
- Use same account and same dataset for all shots.
- Keep status bar and app bar visible.
- Keep Korean copy readable (no clipped text).
- Capture one desktop web set and one mobile set if possible.

## Quality Gate
- No placeholder/debug text.
- No empty cards unless the screen is intentionally an empty-state example.
- Price formatting uses `₩` consistently.
- Active tab state is visible in bottom navigation.
