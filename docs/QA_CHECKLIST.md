# QA Checklist

## 실행 전 준비

- [ ] 최신 코드 기준으로 앱 실행
- [ ] Firebase 프로젝트 연결 확인
- [ ] 테스트 계정 role 확인
- [ ] Firestore rules가 배포 또는 emulator에 반영되어 있는지 확인
- [ ] 브라우저 캐시 영향이 있으면 새 시크릿 창 또는 hard refresh 사용

## 공통

- [ ] 앱이 첫 화면에서 크래시 없이 로드된다.
- [ ] 로그인/로그아웃 상태에 따라 CTA와 접근 가능 화면이 달라진다.
- [ ] 한국어 문구가 깨지지 않는다.
- [ ] 모바일/웹 화면에서 주요 텍스트가 잘리지 않는다.
- [ ] 네트워크 또는 Firestore 오류 발생 시 앱이 크래시하지 않는다.

## 홈

- [ ] 상품 목록이 표시된다.
- [ ] 신상품/세일 등 강조 정보가 표시된다.
- [ ] 카테고리 필터 또는 이동 요소가 정상 동작한다.
- [ ] 상품 카드 이미지, 가격, 상품명이 잘리지 않는다.
- [ ] 하단 영역에서 overflow가 발생하지 않는다.

## 상품 상세

- [ ] 상품 상세 화면으로 이동된다.
- [ ] 상품명, 가격, 이미지, 옵션, 재고 정보가 표시된다.
- [ ] 품절 상품 주문 제한이 동작한다.
- [ ] 장바구니 담기 동작이 정상 처리된다.
- [ ] 뒤로가기 후 이전 목록 상태가 크게 깨지지 않는다.

## 장바구니

- [ ] 장바구니에 담은 상품이 표시된다.
- [ ] 수량 변경이 합계 금액에 반영된다.
- [ ] 상품 삭제가 동작한다.
- [ ] 빈 장바구니 상태가 표시된다.
- [ ] 주문/결제 화면으로 이동된다.

## 주문/결제

- [ ] 배송지 또는 필수 입력값 누락 시 주문이 차단된다.
- [ ] 쿠폰 선택 시 할인 금액이 반영된다.
- [ ] 마일리지 사용 금액이 결제 가능 금액을 초과하지 않는다.
- [ ] 배송비 계산이 기대값과 일치한다.
- [ ] 주문 완료 후 주문 완료 화면으로 이동된다.
- [ ] 주문 생성 후 주문 목록에 표시된다.

## 주문 상세

- [ ] 주문 상태가 표시된다.
- [ ] 주문 상품, 결제 금액, 쿠폰/마일리지 내역이 표시된다.
- [ ] 상태 로그가 표시된다.
- [ ] 취소 가능한 상태에서만 취소 요청이 가능하다.
- [ ] 구매자가 직접 `취소완료`로 변경할 수 없다.

## 리뷰

- [ ] 리뷰 작성 화면 또는 관리 화면에 접근할 수 있다.
- [ ] 리뷰 작성 후 목록에 반영된다.
- [ ] 리뷰 수정이 가능하다.
- [ ] 리뷰 삭제 또는 관리 동작이 정상 처리된다.
- [ ] 리뷰 작성 시 마일리지 적립 정책이 의도대로 동작한다.
- [ ] 확인 필요: 최신 배포본에서 리뷰 E2E 캡처가 존재하는지 확인한다.

## 쿠폰/마일리지

- [ ] 보유 쿠폰 목록이 표시된다.
- [ ] 사용 불가 쿠폰은 결제에 적용되지 않는다.
- [ ] 사용한 쿠폰은 중복 사용되지 않는다.
- [ ] 마일리지 내역이 표시된다.
- [ ] 주문 시 사용/적립 내역이 반영된다.

## 알림

- [ ] 주문 상태 변경 알림이 표시된다.
- [ ] 정책 업데이트 또는 쿠폰 알림이 표시된다.
- [ ] 읽음 처리 후 badge count가 감소한다.
- [ ] 전체 읽음 처리 후 badge count가 0이 된다.
- [ ] 확인 필요: 최신 배포본에서 알림 E2E 캡처가 존재하는지 확인한다.

## 판매자

- [ ] 판매자 계정으로 로그인한다.
- [ ] 판매자 화면에 진입할 수 있다.
- [ ] 본인 seller scope의 상품/주문만 표시된다.
- [ ] 다른 판매자의 주문이 노출되지 않는다.
- [ ] 배송 상태 변경이 가능하다.
- [ ] 운송장 번호 없이 배송 처리 시 차단된다.
- [ ] 취소 요청 주문을 취소 완료로 처리할 수 있다.
- [ ] `npm run audit:sellers` 결과가 PASS인지 확인한다.

## 관리자

- [ ] 관리자 계정으로 로그인한다.
- [ ] 사용자 역할 관리 화면에 진입할 수 있다.
- [ ] 일반 사용자 role 변경이 가능하다.
- [ ] 일반 사용자가 스스로 role을 승격할 수 없다.
- [ ] 정책/FAQ 등록, 수정, 삭제가 가능하다.
- [ ] 비관리자 계정에서 관리자 기능이 노출되지 않는다.

## Firestore Rules / Script QA

```powershell
cd scripts
npm run test:rules
npm run check:accounts
npm run audit:orders
npm run audit:sellers
npm run audit:strings
```

- [ ] rules test가 통과한다.
- [ ] demo account check가 통과한다.
- [ ] order audit에서 issue/warning이 없다.
- [ ] seller audit에서 unknown seller doc이 없다.
- [ ] mojibake string audit가 통과한다.

## 최종 릴리즈 전 확인

- [ ] README의 Demo 링크가 열린다.
- [ ] 최신 스크린샷이 README 또는 docs에 연결되어 있다.
- [ ] 서비스 계정 키, `.env`, 개인 비밀번호가 커밋되지 않았다.
- [ ] `keys/` 폴더가 Git 추적 대상이 아니다.
- [ ] 공개 레포에 불필요한 로컬 로그가 포함되지 않았다.
