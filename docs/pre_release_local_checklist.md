# Local Products Pre-Release Checklist

이 문서는 "상품은 로컬 더미 데이터로 유지"한 상태에서 베타 배포 전 반드시 확인해야 할 항목을 정리한 체크리스트다.

## 1) 구매 플로우 완성

- [ ] 비로그인 사용자는 상품 조회만 가능하고 결제/주문 버튼은 로그인 CTA로 대체된다.
- [ ] 로그인 후 장바구니 -> 결제 -> 주문완료까지 막힘 없이 진행된다.
- [ ] 쿠폰/마일리지 적용 금액이 주문 상세에 동일하게 반영된다.
- [ ] 배송지/결제수단 미선택 시 주문이 차단되고 안내 문구가 표시된다.
- [ ] 주문 생성 후 재고가 감소하고 주문 목록/상세에서 상태 이력이 보인다.

## 2) 권한/보안

- [ ] Firestore 규칙이 공개 모드(`allow read, write: if true`)가 아니다.
- [ ] `users/{uid}`는 본인 계정으로만 읽기/쓰기가 가능하다.
- [ ] 로그아웃 상태에서 사용자 데이터 접근 시 `permission-denied`가 발생한다.
- [ ] 관리자 기능은 관리자 UID에서만 수행된다.

## 3) 안정성/오류 처리

- [ ] 로그인 실패 메시지가 한글로 표시된다.
- [ ] Firestore 네트워크 오류가 발생해도 앱이 크래시하지 않는다.
- [ ] 결제 버튼 연속 탭 시 중복 주문이 발생하지 않는다.
- [ ] 앱 재실행 후 로그인 상태와 사용자 데이터가 정상 동기화된다.

## 4) 운영 준비

- [ ] Firebase Spark 사용량 알림이 설정되어 있다.
- [ ] 테스트 계정/관리자 계정이 분리되어 있다.
- [ ] 테스트 결제만 활성화되어 있고 실제 PG 결제는 비활성이다.

## 5) Firestore 상품 전환 준비(다음 단계)

- [ ] `products` 컬렉션 문서 스키마가 확정되어 있다.
- [ ] 앱에서 상품 로딩 경로가 `Repository`로 분리되어 있다.
- [ ] Firestore 로딩 실패 시 로컬 더미 상품으로 폴백할 수 있다.
